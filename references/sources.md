# Sources and lineage

- **Felix Rieseberg, "How to be more ambitious: A tutorial for humans with models"** (Oct 13, 2026). Altitude, depth, range; the depth questions (what a top professional would do, rawest sources, exact methods, outside check). https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/
- **Anthropic, "Emotion concepts and their function in a large language model"** (Apr 2, 2026). Repeated failure raises a desperation signal that drives gaming checks; calm reduces it. Basis for the honest "not reached" exit. https://www.anthropic.com/research/emotion-concepts-function
- **FrontisAI / OpenRSI** (CC BY-NC 4.0; ideas only, no code or prompt text reused). Append-only journal as source of truth, one change per iteration, frozen evaluation, redesign on a repeated failure signature, ratchet, island diversity. https://github.com/FrontisAI/OpenRSI
- **Prime Intellect / prime-agent** (MIT). Fixed base with small typed lessons that carry evidence and roll back; completion audit against every requirement; blocked must be proven. https://github.com/PrimeIntellect-ai/prime-agent
- **HyperFrames CLI** (npm `hyperframes`, 0.8.x). HTML compositions rendered on a seekable clock.
- **Every** (every.to). A bundle of publication, products and consulting, with product updates launched like films. The model for CETI's first three products (Oneline, Seam, Lineage).
- **The Loop brief** (20 s note-taking app launch). The constraints this meta-prompt generalises: a single red line that ends as the logo, transform-only transitions, code-built UI, synthesized sound frame-locked to action, multi-round senior critique.
- **Manu's HyperFrames pipeline** (stages S0–S9, typed packets, maker/checker split). The stage structure the meta-prompt keeps and extends.
